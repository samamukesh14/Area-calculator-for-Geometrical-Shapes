Geometric Area Calculator

Project Title:
Geometric Area Calculator – Python Programs




Overview of the Project :

This project contains a collection of beginner-friendly python programs that calculate the area of different geometric shapes. Each program accepts the required measurements from the user , applies the appropriate mathematical formula and displays the result.




The project covers the following shapes:

Circle
Parallelogram
Rhombus
Trapezoid
Rectangle
Square
Triangle

The programs are organized into separate folders according to the shapes they calculate , making the project easy to understand and run.




Features:

Calculate area of circle
Calculate area of parallelogram
Calculate area of rhombus
Calculate area of trapezoid
Calculate area of rectangle
Calculate area of square
Calculate area of triangle
Accept dimensions from the user through the terminal.
Display the calculated area as output.
Simple Python programs suitable for beginners.
No external Python packages are required.




Technologies / Tools Used:

Python 3 – Programming language used for the programs.
Visual Studio Code – Used to write, edit, and run the Python files.
Python Standard Library – Used for basic mathematical calculations.
